# \# AutoLoc

# 

# Plateforme de gestion de location de véhicules multi-agences.

# Projet réalisé dans le cadre du module Architecture des Systèmes d'Information (UP ASI, ESPRIT).

# 

# \## Objectifs du projet

# \- Gérer le parc de véhicules de plusieurs agences

# \- Permettre aux clients de réserver et de louer un véhicule

# \- Suivre les contrats, les retours et la facturation

# \- Exposer une API REST documentée (Swagger) et testée

# 

# \## Acteurs

# \- \*\*Client\*\* : consulte les véhicules, réserve, suit ses locations

# \- \*\*Agent d'agence\*\* : enregistre les locations, les retours et les paiements

# \- \*\*Responsable d'agence\*\* : gère son agence (véhicules, agents, statistiques)

# \- \*\*Administrateur\*\* : gère les agences, les comptes et la configuration globale

# 

# \## Stack technique

# Java 17, Spring Boot, Spring Data JPA, MySQL, Maven, Lombok, Postman, Git.
